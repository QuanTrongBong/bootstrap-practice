# Bootstrap Practice

Bốn bài thực hành Bootstrap 5.3 trong cùng một project:

1. `company/` — trang giới thiệu doanh nghiệp với navbar, hero, grid cards và footer.
2. `grid-system/` — responsive two-column layout và navbar dropdown.
3. `registration-form/` — form đăng ký với validation phía trình duyệt.
4. `landing-page/` — landing page responsive với hình ảnh, features và CTA.

Mở `index.html` ở thư mục gốc để chọn bài. Bootstrap CSS/JS được tải từ jsDelivr CDN, do đó cần kết nối Internet khi xem trang.
