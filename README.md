# Bootstrap Practice

Chín bài thực hành Bootstrap, mỗi bài nằm trong thư mục riêng:

1. `company/` — giới thiệu doanh nghiệp với navbar, hero, dịch vụ và footer.
2. `grid-system/` — responsive two-column layout và navbar dropdown.
3. `registration-form/` — form đăng ký với radio, checkbox, select và validation.
4. `landing-page/` — landing page responsive với hình ảnh, features và CTA.
5. `store-layout/` — bố cục cửa hàng dùng Bootstrap 3, Glyphicons, sidebar và danh mục sản phẩm.
6. `bootstrap-home/` — trang chủ dùng Bootstrap 5, Font Awesome, Carousel và form liên hệ.
7. `grid-flexbox/` — bố cục ba cột, spacing utilities, responsive visibility, carousel và form.
8. `registration-carousel/` — carousel giới thiệu và form đăng ký có validation.
9. `product-page/` — trang giới thiệu sản phẩm hư cấu, dùng Grid, Flexbox và spacing utilities.

Mở `index.html` để chọn bài. Các trang tải Bootstrap và icon fonts từ CDN, cần kết nối Internet để xem đầy đủ.
